# Tailormap Planmonitor Wonen

Project contains code for the planmonitor wonen extension on Tailormap

## Start with the API documentation

This frontend is the web application on top of
[planmonitor-wonen-api](https://github.com/B3Partners/planmonitor-wonen-api), which holds most of the documentation (in
Dutch). Read that first to find out what's what: the data model of a planregistratie and its validation rules, the
differences with the basisset 2.0, and how gemeente software delivers plans through the API. The
[README](https://github.com/B3Partners/planmonitor-wonen-api/blob/main/README.md) of the API describes how to open the
OpenAPI documentation with Swagger UI on a running server.

## Security

See the [security policy](https://github.com/B3Partners/planmonitor-wonen-api/blob/main/SECURITY.md) of
planmonitor-wonen-api to report a vulnerability.
